Every web page is three layers, stacked.

A working reference for the three languages that build the web: what each one is for, the core ideas worth knowing cold, and a live playground to test them. Built for exam prep now, and useful the day you're asked to build something real.

HTML — structure

Defines what's on the page and what each piece means, not how it looks.

Elements and nesting

A page is a tree of elements. Each tag describes the role of the content it wraps — a heading, a paragraph, a link — and elements nest inside each other to build structure.

<article>
  <h1>Page title</h1>
  <p>A short paragraph.</p>
</article>

Semantic tags

Tags like <nav>, <header>, <main>, and <footer> describe the purpose of a region. This helps screen readers, search engines, and anyone reading your code later.

<nav>...</nav>
<main>...</main>
<footer>...</footer>

Attributes

Attributes add extra information to a tag — a link's destination, an image's source, a form field's name.

<a href="/about">About</a>
<img src="cat.jpg" alt="A cat">

CSS — style

Controls how the structure looks: color, spacing, layout, and responsiveness.

Selectors and rules

A selector picks which elements a rule applies to. Rules are property–value pairs inside braces.

p {
  color: #333;
  font-size: 16px;
}

The box model

Every element is a box made of content, padding, border, and margin, from the inside out. Most layout bugs come from misunderstanding this.

.card {
  padding: 16px;
  border: 1px solid #ccc;
  margin: 12px;
}

Flexbox for layout

Flexbox arranges children in a row or column and distributes space between them — the most common tool for everyday layout.

.row {
  display: flex;
  justify-content: space-between;
}

JavaScript — behavior

Makes the page respond: react to clicks, change content, talk to servers.

Variables and functions

Variables store values; functions bundle steps you can reuse.

let count = 0;
function increment() {
  count = count + 1;
}

Selecting and changing elements

JavaScript can find an element in the page and change its content or style directly.

const title = document.querySelector("h1");
title.textContent = "Updated!";

Event listeners

An event listener runs code in response to something happening — a click, a key press, a page load.

button.addEventListener("click", () => {
  increment();
});

Quick reference

HTML tags

<div>generic block container
<span>generic inline container
<ul>/<li>bullet list and items
<form>collects user input
<input>a single form field
<table>tabular data

CSS properties

displayblock, flex, grid, none
positionstatic, relative, absolute, fixed
gapspace between flex/grid children
grid-template-columnsdefines a grid's columns
transitionanimates a property change
@mediaconditional rules by screen size

JS methods

querySelector()find one matching element
addEventListener()run code on an event
fetch()request data from a server
JSON.parse()text → JS object
array.map()transform each item in a list
console.log()print for debugging

Turning this into something for your job

  1. Rebuild this stack idea as your own portfolio page — swap the content for a project of yours and the three-layer mental model still applies.
  2. Practice by recreating one small real website's layout using just HTML and CSS, without looking at its code.
  3. Add one small interactive feature with JavaScript — a toggle, a counter, a filter — and be ready to explain how it works in an interview.
  4. Push your code to GitHub. A public repo with clean commits is often the first thing an employer checks.
